# 假人接入 AI 设计（v0.7.0，2026-10-23 Fong 拍板"全都做"）

## 背景与实测前提（本机 Leaves 1.21.1 #81 探针实测）

- 假人（Leaves /bot）在插件眼里是 `org.leavesmc.leaves.entity.CraftBot`，Bukkit 按 Player 读写（位置/背包/血量/饥饿都是真的）。
- 速度驱动可行：每 2 tick 给方向速度即可行走（7 格 <1 秒）；小步传送作卡住兜底。
- `HumanEntity.sleep()` 对假人不稳（force=true 返回 true 但睡姿随即被清）→ 作息改为"回据点床边休息"，不强求躺姿（真服夜里再复测自然睡）。
- `/bot action break` 敲视线方块可用；掉落物需自己挪过去捡。
- 控制台 `/bot create 名字 皮肤 x y z` 坐标被忽略（出生在世界出生点）→ 流程：先创建、后传送到岗位。
- 控制面 = 控制台命令（/bot create/remove/action/save/load）+ Bukkit API，不依赖 Leaves API jar。

## 分工原则（沿用全项目铁律）

- 插件定规矩与结果：派活命令走插件确定性解析（跟我来/去钓鱼/挖矿/回家/存箱子/盖房/守夜/停下），不经模型。
- 模型只有表达权：假人聊天台词由模型按性格生成；事实（饿/伤/背包）由插件直报。

## 模块（新包 com.howard.mcai.bot）

- `BotState`：账号名（英文，游戏规则）、中文名、性别、人格标签（复用 PersonalityTagLibrary）、
  对各玩家好感、事实记忆、据点（床+箱子位置）、当前工作、出生皮肤。Gson 持久化 bots.json。
- `BotService`：招募/认领/遣散/持久化/每秒大脑 tick 注册点；死亡记账（档案保留，同名再招募=本人回来）。
- `BotDriver`：速度方向盘沿路点行走（NavService 局部算路 + 长途分段直奔），跳跃辅助，
  卡住检测→无人看见时小步瞬移补位（沿用跟随"跟丢规矩"的体面线）。
- `BotBrain`：生存优先（吃东西/低血撤退回血）→ 工作状态机 → 闲时社交。
- `BotJobs`：站桩活（钓鱼/砍面前树/敲石）、直线矿道、守夜打怪、存箱子、建房（图纸施工）。
- `HutBlueprint`（纯计算可单测）：5×5 小屋图纸（墙/顶/门洞/床/箱子位）与材料清单计数。
- `DepositPlan`（纯计算可单测）：存箱取舍——保留口粮与工具基线，其余全存。
- `BotChatService`：凑近（5 格）或喊名字接入对话；命令先行解析，未命中才走模型聊天；
  台词由插件以「[中文名>玩家]」格式代发（与村民台词同制式）。

## 作息与据点

- 据点 = 他的床 + 他的箱子。建房后据点搬进新房。
- 夜里：近据点回据点床边休息；远行在外就找平地停下过夜（Fong 定：不必回家、范围不限）。
- 背包满或受令：回据点把货存进他的箱子（保留口粮/工具）。

## 已知边界（交付时如实标注）

- 走路是速度方向盘，不是原版导航：复杂地形会卡，靠兜底补位；长途靠分段推进。
- 盖房放砖由插件按图纸逐块施工（扣他背包真材料、他站在工地边），不是他逐块瞄准放。
- 挖矿 v1 只做直线矿道 + 斜梯下行，不做分支矿洞寻钻。
